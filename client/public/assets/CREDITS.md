# Asset credits

No external assets yet. All models (bus, riders, zombies, props, roadblock) are procedural
Three.js primitives, and all sounds are synthesised with WebAudio, so there is nothing to license.
When CC0 packs (Kenney, Quaternius, KayKit) are added, record each here with source URL and licence.

## Route data

- Road geometry: OpenStreetMap contributors, Open Database Licence (ODbL) 1.0. https://www.openstreetmap.org/copyright
- Elevation: NASA Shuttle Radar Topography Mission (SRTM), public domain. https://www.earthdata.nasa.gov/data/instruments/srtm
