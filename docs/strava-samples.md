# Strava post samples

What `server/src/zombie_bus_server/strava_text.py` writes for three made-up rides (`server/tests/strava_samples.py`), generated by running it, so these are exactly what Strava would get. The title is the activity name; everything under it is the description. Each group shows at most four lines (a game's result eight) before "+ N more", and the whole thing is cut tighter if it would run past 1,500 characters. The old power bests and the crew placings come from the server's own records when the ride is uploaded.
